# Connie Book 90-Day Roadmap

## Overview

This roadmap covers the first 90 days of the project. It balances three goals:

1. establish a sustainable writing practice
2. teach AI tools through real use
3. learn Symphony-style orchestration while maintaining a disciplined backlog

The system is intentionally light. Weekly work should generally fit within 4-6
focused hours.

## Milestones

| Milestone | Window | Outcome | Primary Backlog |
|-----------|--------|---------|-----------------|
| M1 Bootstrap | Weeks 1-2 | Workspace, agent team, workflow contract, and initial curriculum exist | `CBOOK-000` to `CBOOK-005` |
| M2 Book Framing | Weeks 3-4 | Book direction, target reader, theme, and working outline are defined | `CBOOK-006`, `CBOOK-007`, `CBOOK-009` |
| M3 Drafting System | Weeks 5-8 | A repeatable drafting, research, and revision loop is working | future drafting items |
| M4 Portfolio Proof | Weeks 9-10 | Reusable artifacts show writing progress and AI fluency | `CBOOK-010` and follow-ons |
| M5 Quarter Close | Weeks 11-12 | Lessons are consolidated and the next quarter is chosen | future review items |

## Phase Plan

### Phase 1: Bootstrap

**Weeks 1-2**

- Create the `connie-book/` source-of-truth documents
- Define the agent roster and mission files
- Build the first backlog
- Write the first version of the 12-week lesson plan
- Simulate the first Symphony-style run

### Phase 2: Book Framing

**Weeks 3-4**

- Decide the book category and working promise
- Identify the ideal reader and the core emotional or practical payoff
- Build a living outline and list of likely chapters or sections
- Start a repeatable note-capture habit using AI support

### Phase 3: Drafting System

**Weeks 5-8**

- Draft short sections before full chapters
- Practice AI-supported outlining, summarization, and revision
- Build a simple research intake and source-note workflow
- Capture voice notes, convert them into rough prose, and refine

### Phase 4: Portfolio Proof

**Weeks 9-10**

- Convert selected work into portfolio evidence
- Save example prompts, revision passes, summaries, and research memos
- Produce one polished excerpt and one process artifact that demonstrates
  AI-enabled work

### Phase 5: Quarter Close

**Weeks 11-12**

- Review what worked and what created friction
- Tighten the lesson plan and backlog
- Decide whether the next quarter focuses on drafting depth, publication prep,
  or employability artifacts

## Weekly Cadence

### Human Rhythm

- One weekly planning review led by Lee and Connie
- Two or three short focused work sessions during the week
- One weekly retrospective note: what helped, what stalled, what to change

### Agent Rhythm

- Hourly wake-up loop reviews backlog and context
- Each run advances at most one eligible backlog item
- Each run updates `RUN_LOG.md` and the relevant planning artifact
- Each run performs a short workflow-and-agent improvement check before closing
- Escalate to human review when the task changes project direction or workload

## Weekly Time Budget

| Activity | Target Time |
|----------|-------------|
| Planning and review | 30-45 minutes |
| Writing session 1 | 60-90 minutes |
| Writing session 2 | 60-90 minutes |
| AI-tools practice | 60 minutes |
| Optional cleanup or reflection | 30-45 minutes |

## Exit Criteria For The First 90 Days

- A clear book direction exists, even if the final title does not
- Connie has completed the full 12-week lesson plan
- At least one working outline and multiple drafted sections exist
- A reusable AI workflow exists for brainstorming, outlining, revising, and
  summarizing
- The backlog and workflow system are stable enough for continued hourly runs
